Selected work

ICLR 2026
Poster

Verification and Co-Alignment via Heterogeneous Consistency for Preference-Aligned LLM Annotations

Cheng Chen, Haiyan Yin, Ivor W. Tsang

Uses agreement between an LLM and a task-specific encoder to assess annotation reliability without reference labels. The method uses embeddings to recalibrate annotations when the two models disagree.

PaperCode
TMLR 2025

Unlearning Misalignment for Personalized LLM Adaptation via Instance-Response-Dependent Discrepancies

Cheng Chen, Atsushi Nitanda, Ivor Tsang

Introduces Consistent Marginalization, which builds a memory bank from a small set of preference examples to adapt responses to an individual user and context.
